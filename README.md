## 🔍 Understanding the Data

This tool works by fetching specific details about companies. When you ask your AI about a business, this software provides the following information:

*   Corporate Hierarchy: It identifies if a business is a branch of a larger parent company.
*   Investment Ties: It shows if a private equity firm backs the business.
*   Portfolio Siblings: It lists other companies under the same ownership group.
*   Data Enrichment: It adds context to standard company names so your AI makes fewer mistakes.

## 🛡 Security and Privacy

This software acts as a bridge between your AI and public databases. It only retrieves information about corporate entities. It does not access your private documents or local personal data. All requests stay within the standard framework of the Model Context Protocol.

## 📈 Performance Tips

For the best results, keep your database links current. This software pulls from public records. The accuracy depends on how often those records change. If you manage large lists of companies, perform your lookups in small batches to maintain consistent speeds.
